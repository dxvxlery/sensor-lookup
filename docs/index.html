Set up in a minute

Needs BetterDiscord and an account on the data source.

Step 1
Download
Get the plugin from the latest release.
Step 2
Drop it in
Settings → BetterDiscord → Plugins → Open Plugins Folder.
Step 3
Enable and connect
Turn on SensorLookup and copy three values from your browser.
Account connection

Copy. Don’t paste.

With the settings open, the plugin catches the values you copy, saves them and wipes the clipboard. Press Check to confirm it works.

Everything stays on your computer and is sent only to the data source. Never share the plugin’s config file.
